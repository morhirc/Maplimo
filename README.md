# Maplimo

**地図から、あの日をたどる。**

Maplimo（マプリモ）は、Android から書き出した Google Maps Timeline の
`タイムライン.json` を PC のブラウザで読み込み、過去の訪問場所や移動記録を
地図上で振り返るための非公式ビューアです。

> Google 公式のアプリ・サービスではありません。

## 主な機能

- `タイムライン.json` を選択、またはドラッグ＆ドロップで読み込み
- 日付ごとの訪問場所・移動・経路を地図表示
- 年・月・日から記録を移動
- 「北海道」「札幌」など、地域名から行った日を検索
- 地域検索の候補日を残したまま、日付を切り替えて振り返り
- 「あの日へワープ」「○年前の今日」
- 旅行一覧
- 最長移動・よく訪れた場所のランキング
- 行った都市の一覧表示
- 行った都市を日本全体の地図上に表示
- 都市マーカーをクリックして、その都市へ行った日を表示
- お気に入りの日
- 日ごとの思い出メモ
- Google マップで該当座標を開く

## タイムラインJSONを用意する

Maplimoで使うデータは、スマートフォンに保存されているタイムラインデータを
JSONファイルとして書き出して用意します。

### Android

1. Androidの **設定** アプリを開きます。
2. **位置情報** → **位置情報サービス** → **タイムライン** を開きます。
3. **タイムライン データをエクスポート** を選びます。
4. **続行** を押し、保存場所を選んで保存します。

書き出されたタイムラインJSONをPCへコピーし、Maplimoで読み込んでください。

### iPhone / iPad

Google マップのタイムライン画面から **位置情報とプライバシーの設定** を開き、
**タイムライン データをエクスポート** を選びます。

※ 端末・OS・アプリのバージョンによって、表示名や手順が変わる場合があります。
最新の手順は Google のヘルプをご確認ください。

GoogleおよびGoogle マップは、それぞれの権利者の商標またはサービス名称です。

## 使い方

1. `Maplimo_v1.0.html` を Chrome / Brave などのブラウザで開きます。
2. 「タイムライン.json を選ぶ」を押して、Android から書き出した
   `タイムライン.json` を選択します。
3. 読み込み後、最新日の記録が表示されます。
4. 左側の各機能から、過去の記録を自由にたどれます。

ドラッグ＆ドロップでも JSON を読み込めます。

## 地域検索

検索欄に、例えば次のように入力して **Enter** を押します。

- 北海道
- 札幌
- 長野
- 大阪

検索した地域に含まれる訪問記録の日付が一覧表示されます。
「細かい場所名は覚えていないけれど、北海道へ行った時期を探したい」
といった使い方を想定しています。

## 行った都市

「🏙 行った都市」を押すと、取得済みの場所情報から都市を集計し、
訪問回数と訪問日を一覧表示します。

地図上の都市マーカーをクリックすると、その都市へ行った日を表示できます。

場所情報がまだ取得されていない訪問地点は、外部サービスへの大量アクセスを
避けるため、5地点ずつ追加取得できます。

## プライバシーについて

読み込んだ `タイムライン.json` 本体は、ブラウザ内で処理されます。
Maplimo がタイムライン JSON 全体をサーバーへアップロードすることはありません。

ただし、以下の機能では外部サービスへ通信します。

- 地図表示: OpenStreetMap の地図タイル
- 場所名・住所の取得: OpenStreetMap Nominatim
- 地域検索: OpenStreetMap Nominatim
- 「Googleマップで場所を見る」: Google Maps

Nominatim を利用する際は、検索語や緯度経度が送信されます。
取得した場所名・住所はブラウザの `localStorage` にキャッシュされます。

お気に入り・思い出メモもブラウザの `localStorage` に保存されます。

## ネット接続

Maplimo 本体は単一 HTML ファイルですが、地図表示や場所名検索のために
インターネット接続が必要です。

## サンプルデータ

`sample_timeline.json` は公開場所を使った架空のサンプルです。
実際の個人行動履歴は含まれていません。

## 対応データについて

Maplimo は、Android から書き出した Timeline JSON のうち、
`semanticSegments` を含む形式を対象にしています。

Google 側のエクスポート形式が将来変更された場合、読み込めなくなる可能性があります。
